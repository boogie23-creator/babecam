# 기록도우미 (상태변화 기록 도우미)

재가 방문요양 요양보호사가 **말로** 어르신 상태를 남기면, AI(Google Gemini)가
상태변화기록지 4개 영역(신체상태, 영양상태, 질병상태, 개별욕구)으로 나누고
스마트장기요양 앱 특이사항 칸에 붙여넣을 문장으로 정리해 주는 안드로이드 앱입니다.

## 기능
- 🎤 말로 입력하기 (안드로이드 음성인식, 한국어)
- 영역별 상태 표시: 변화 있음 / 평소와 같음 / 언급 없음
- 사회복지사·보호자 보고가 필요한 변화 알림
- 특이사항 문장 수정 후 복사
- 다음 방문 때 확인할 점 제안

## 설치
GitHub → Actions → 최신 "Build APK" 실행 → 아래 Artifacts의 `care-note-debug-apk` 다운로드 → 압축 풀고 APK 설치.

## 처음 설정
앱 오른쪽 위 ⚙️ → Google AI Studio에서 Gemini API 키를 만들어 붙여넣고 저장.
API 키는 **휴대폰 안에만 저장**되며 이 저장소(코드)에는 들어 있지 않습니다.

## 개인정보 주의
- 어르신 실명·주민번호·주소·연락처는 입력하지 말고 이니셜만 사용합니다.
- 입력 내용과 정리 결과는 휴대폰에 저장하지 않습니다.
- Gemini 무료 요금제는 입력 내용이 구글 서비스 개선에 쓰일 수 있어, 실제 현장 사용 전에는 유료 계정 또는 별도 서버 방식으로 바꾸는 것을 권장합니다.
- AI 정리 결과는 초안이며, 건강 판단은 간호사·의료진에게 확인합니다.
